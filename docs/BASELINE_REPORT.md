## 关键风险

1. `raw_items` 仍包含 `task_id`，无法实现跨任务全局去重。
2. AI 成功记录与规则兜底未完全解耦，可能把规则结果误解为 AI 分析。
3. 运行结构化日志、合法状态机、平台锁、心跳与断点恢复尚未完成。
4. 知乎连接器集中在单个本机助手文件，选择器与日期解析缺少 fixture 测试。
5. 仅有知乎单源，尚未达到至少两个真实来源的最终验收门槛。
6. CSV/XLSX/URL 导入尚未实现。
7. Excel 字段、公式注入、大数据量处理未达到交付标准。
8. 缺少 200 条由业务人员标注的脱敏真实评测集。
9. Windows、7 天 / 50 次 / 5000 条稳定性指标需要真实环境和时间验证。

## Phase 0 结论

当前产品是“知乎单源、可进行业务可行性验证的 MVP”，不是总计划定义的“可真实交付 MVP”。后续阶段不得在上述门槛通过前标记为已交付。
