# 支持能力真实性矩阵

更新日期：2026-08-28

状态定义：`已实现` 表示代码路径和自动测试存在；`部分实现` 表示仍缺少计划规定的交付验证；`未实现` 不得在产品中宣称支持。

| 能力 | 当前状态 | 真实边界 / 缺口 |
|---|---|---|
| 多任务 CRUD | 已实现 | 创建、编辑、暂停、恢复、删除；仍需任务版本和草稿向导 |
| JD 拆解 | 部分实现 | 当前为芯片词库规则解析；尚无 AI Schema、版本化 ontology 和完整人工确认向导 |
| 知乎本机浏览器采集 | 部分实现 | macOS 真实账号已做单轮验证；Windows、连续 10 次、断点恢复尚未验收 |
| EETOP | 未实现 | 尚未完成技术与合规验证 |
| EDA365 | 未实现 | 尚未完成技术与合规验证 |
| CSV/XLSX/URL 导入 | 未实现 | 无导入预览、表头映射和批次报告 |
| 原始内容保存 | 部分实现 | 当前 raw_items 仍按任务保存，不是全局内容库 |
| 增量去重 | 部分实现 | 当前按任务指纹去重；尚未实现跨任务全局去重和 canonical URL |
| AI 结构化分析 | 部分实现 | 本机助手可调用 Responses API；服务端仍存在关键词兜底，不符合最终验收 |
| 人才/企业情报分离 | 部分实现 | 具备基础分类；尚无版本化 analyses 和独立确定性评分 |
| 证据引用 | 部分实现 | 可显示证据；服务端尚未验证引用确实存在于原文 |
| 人工复核 | 部分实现 | 支持确认/误报；缺少忽略、稍后处理、备注和复核审计字段 |
| 筛选与导出 | 部分实现 | 支持常用筛选和 XML Excel；尚缺分页、完整字段、公式注入防护和大批量导出 |
| 手动运行 | 已实现 | 受知乎登录、页面结构和 AI 配置影响 |
| 后台增量扫描 | 部分实现 | 有调度入口；缺少统一锁、心跳超时和断点恢复 |
| 结构化运行漏斗 | 部分实现 | 有聚合数量；尚无 run_source_stats 和 run_events |
| macOS 本机助手 | 部分实现 | 当前可运行；安装包与正式安装验收未完成 |
| Windows 本机助手 | 未验证 | Chrome 探测仍需跨平台重构和实机验收 |
