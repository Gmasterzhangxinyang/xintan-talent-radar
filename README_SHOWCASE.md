# 芯探 Talent Radar

面向芯片行业猎头的知乎人才与企业信号发现助手。

演示地址：[https://xintan-talent-radar.iyihioh.chatgpt.site/](https://xintan-talent-radar.iyihioh.chatgpt.site/)

> 当前为可演示、可验证的 MVP 版本，现阶段专注知乎数据源。

## 现在能做什么

- 创建多套检索任务，分别配置技术栈、目标企业、求职信号、时间范围和黑名单。
- 粘贴 JD，自动拆解职位、技能、企业及人才信号关键词。
- 使用本机已经登录的知乎账号执行检索，并优先查看最新内容。
- 像人工一样逐条工作：搜索 → 打开内容详情 → 分段阅读正文 → 展开并逐条查看评论 → AI 判断价值 → 继续下一条。
- 采集公开昵称/ID、发布时间、原文片段和原始来源 URL。
- 识别裁员、扩招、项目变动、流片问题、求职意向等碎片化信号。
- 按价值和求职意向对线索进行评分、分级和排序。
- 在线索列表中筛选、复核、标记状态，并直接跳转原始页面。
- 按当前筛选条件导出 Excel。
- 支持立即检索和后台增量扫描，自动去重，并记录抓取、过滤和失败日志。
- 执行时可看到浏览器正在阅读的位置、当前步骤、已读正文和评论数量。

## 标准工作流程

1. 启动本机电脑助手，并确认知乎已登录。
2. 粘贴 JD 自动生成关键词，或手动创建检索任务。
3. 设置时间范围、黑名单和本次深读数量。
4. 点击“立即运行”，观察 AI 逐条打开、阅读和判断内容。
5. 在线索中心复核结果，按标签、等级、时间等条件筛选。
6. 将有效线索导出为 Excel，供后续寻访或企业情报研判使用。

## 当前边界

- 当前只接入知乎；微博、小红书、抖音等平台尚未纳入这一版本。
- 仅处理登录账号有权访问的公开信息，不绕过验证码、权限或平台安全机制。
- 遇到登录失效、验证码或页面结构变化时会暂停并提示人工处理。
- 不自动私信、点赞、评论或发布内容，现阶段只做检索、阅读、分析和整理。
- 线索质量取决于任务关键词、知乎实际搜索结果和账号可见内容；无关内容会被过滤，不会为了凑数量强行保留。
- 当前已达到 MVP 演示和业务可行性验证水平，正式商用前仍建议进行更长时间的连续运行与异常恢复测试。

## 适合验证的业务价值

- 是否能从近期知乎内容和评论中发现潜在候选人信号。
- 是否能更早捕捉企业裁员、扩招、项目调整和流片异常等情报。
- 是否能减少猎头人工搜索、逐条阅读、复制整理和初步判断的时间。
- 是否能形成可追溯、可筛选、可复核、可导出的线索库。
